## 多层感知机
### 线性模型的问题
#### 单调性问题
线性模型比较死板，对特征的计算是单向的，要么一直增加要么一直减小，比如模型认为收入越高，信用越好
但是我们的现实生活往往不是线性的，拿体温与死亡率来举例，当权重确定后，模型往往认为体温大于 37 度越高，死亡率越高，而现实生活中是低于正常温度很多也会死亡率变高，所以面临着一个非单调性----体温过高或者过低都不健康，一个解决办法就是换算成与正常温度的距离
#### 图像识别困境
对于比较复杂的图像，单个像素点决定这张图片是猫还是狗一般没有任何线性关系，而线性模型会将图像展平成一个向量，而每个像素点代表一个特征，这回导致"如果某个像素点值更大它就是狗"的情况出现，而实际情况是当图像稍微平移，这个高亮值就变位置了，但图片还是狗，这是我们不能通过特殊处理来解决的，此时，每个像素点的意义就在于它的上下文，要将像素点放在上下文里才有意义

### 隐藏层
加入隐藏层后，能处理更普遍的函数关系类型
最简单的方法就是堆叠多个全连接层，然后最后一层为线性预测器，这种架构为多层感知机（MLP），不过这样意味着相邻两层全连接层之间每个神经元之间都有连接，然而每个连接都代表着一个参数，所以多层感知机的参数开销会很高
输入： $\mathbf{X} \in \mathbb{R}^{n \times d}$
隐藏层输出：$\mathbf{H} \in \mathbb{R}^{n \times h}$
计算方式：
$$\mathbf{H} = \mathbf{XW}^{(1)} + \mathbf{b}^{(1)},$$$$\mathbf{O} = \mathbf{HW}^{(2)} + \mathbf{b}^{(2)}.$$
最后带入 $$\mathbf{O} = (\mathbf{XW}^{(1)} + \mathbf{b}^{(1)})\mathbf{W}^{(2)} + \mathbf{b}^{(2)} = \mathbf{XW}^{(1)}\mathbf{W}^{(2)} + \mathbf{b}^{(1)}\mathbf{W}^{(2)} + \mathbf{b}^{(2)} = \mathbf{XW} + \mathbf{b}.$$
其中 $\mathbf{W} = \mathbf{W}^{(1)}\mathbf{W}^{(2)}$ 然后 $\mathbf{b} = \mathbf{b}^{(1)}\mathbf{W}^{(2)} + \mathbf{b}^{(2)}$
为了防止多层感知机退化为线性模型，我们还会在计算后对每个隐藏单元应用非线性的激活函数 $$\mathbf{H} = \sigma(\mathbf{XW}^{(1)} + \mathbf{b}^{(1)}),$$
**==只对隐藏层使用==**$$\mathbf{O} = \mathbf{HW}^{(2)} + \mathbf{b}^{(2)}$$
通过加入隐藏层，我们可以更容易逼近许多函数

### 激活函数
#### ReLu
$$
ReLu(x)=max(x, 0)
$$
![[output.svg]]
ReLu 函数在输入为负数时导数为 0，正数时导数为 1，而输入为 0 时不可导
![[output 1.svg]]
#### Sigmoid
在定义域 $R$ 中，sigmoid 能将输入变化到区间 $(0,1)$ 上的输出，所以 sigmoid 被称为挤压函数 ![[output 2.svg]]
$$\frac{d}{dx}\text{sigmoid}(x) = \frac{\exp(-x)}{(1 + \exp(-x))^2} = \text{sigmoid}(x)(1 - \text{sigmoid}(x)).$$
可以见得，当输入越远离 0 的时候，导数越接近 0
![[output 3.svg]]
#### Tanh
这个激活函数与 sigmoid 相似，是将实数域的输入压缩到 $(-1,1)$ 之间 $$\tanh(x) = \frac{1 - \exp(-2x)}{1 + \exp(-2x)}.$$
![[output 4.svg]]
Tanh 的导数为，它的图像和 sigmoid 类似，也是在 0 时取得最大值 $$\frac{d}{dx}\tanh(x) = 1 - \tanh^2(x).$$
![[output 5.svg]]
#### 激活函数作用
在神经网络中，如果没有激活函数，无论多少层，最终的结果都是一个巨大的线性变换，比如你在玩复杂的拼图，如果没有激活函数，你只能在地面上旋转平移，无法折叠成三维的，而激活函数就是折痕，能赋予网络处理复杂非线性数据的能力

**比如拿 ReLu 举例子**
在反向传播求导时，relu 函数对 x 小于 0 的导数都为 0，对 x 大于 0 的，导数都为 1，带来的好处首先是计算很简单，只需要一个 if 语句，其次是能够解决大于 0 区域的梯度消失，比如 sigmoid 函数导数最大值为 0.25，如果有 20 层网络，在反向传播到第一层的时候，值已经变成了 $0.25^{20}$ ，所以几乎等于 0 了，模型参数根本不会更新，而且还能解决一个稀疏性（类似于 dropout），即有些神经元计算是负数，所以不需要更新（更新这些神经元参数对模型作用不大），这样更能有效提取关键特征，提高泛化。
坏处就是，有些神经元始终为负数，会导致这个参数权重一直不更新，为了处理这种问题，更新了一个 $$
LeakyReLu(x) = max(0.01x, x)
$$
相当于是给了它一点小的机会能传回梯度
