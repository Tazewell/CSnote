# 线性回归
### **线性模型**
给定一个数据集，目标是寻找模型的权重（w）和偏置（bias）
### **损失函数**
量化目标的实际值与预测值的差距，一般数值越小表示损失越小，回归问题一般用均方误差
$$
l^{(i)}(w, b)=\frac{1}{2}(\hat{y_{(i)}}-y_{(i)})^2
$$
度量整个数据集的损失，我们对每项求和再除以 n 得到平均损失
训练模型时，我们希望找到一组 $(w^*,b^*)$，这组参数能够最小化损失
### 随机梯度下降
不断地在损失函数递减地方向更新参数，梯度下降一个比较简单的方法便是求出损失函数关于模型参数 $(w^*,b^*)$ 的导数（也称为梯度），在一次遍历的时候，我们必须对整个数据集进行遍历，所以这个计算过程比较大，因此在实际计算中，我们可以通过随机选取一个批次 $\mathcal{B}$，相当于用样本代表整体来对参数进行更新，具体的更新过程如下（用常用的平方损失举例）$$l^{(i)}(\mathbf{w}, b) = \frac{1}{2} (\hat{y}^{(i)} - y^{(i)})^2$$
$$\hat{y}^{(i)} = \mathbf{w} \cdot \mathbf{x}^{(i)} + b$$

1. 求出损失函数对每个参数的导数
	1. 先是外部求导 $\frac{\partial l}{\partial \hat{y}} = (\hat{y}^{(i)} - y^{(i)})$
	2. 然后再对内部的 $\hat{y}^{(i)}$ 求导 $\frac{\partial \hat{y}}{\partial w_j} = x_j^{(i)}$ 
	3. 最后链式相乘分别得到每个损失函数对每个参数的导数 $$\frac{\partial l^{(i)}}{\partial w_j} = \frac{\partial l}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial w_j} = (\hat{y}^{(i)} - y^{(i)}) x_j^{(i)}$$$$\frac{\partial l^{(i)}}{\partial b} = (\hat{y}^{(i)} - y^{(i)}) \cdot 1 = \hat{y}^{(i)} - y^{(i)}$$
2. 小批次求和求平均
	1. 对该批次的导数累加
	2. 累加和求均值除以批次的绝对值大小
3. 然后 $(w^*,b^*)$ 分别更新每个参数，更新时要根据学习率
	1. $$w_{new} = w_{old} - \frac{\eta}{|\mathcal{B}|} \sum (\text{误差} \times x)$$
	2. $$b_{new} = b_{old} - \frac{\eta}{|\mathcal{B}|} \sum (\text{误差})$$
小技巧，在计算中，我们可以给特征多加一个维度，由原来的 n 维变成 n+1 维，把 bias 放在最后一列，这样原式就能变成 $y = W'X'$，在数学形式上就合二为一了，也不用分开计算梯度了
### 均方损失（MSE）
数据在现实世界中是有噪音的，拿房价来举例 $$y = \mathbf{w}^\top \mathbf{x} + b + \epsilon$$
而这个噪音服从正态分布（高斯分布），由于高斯分布中，+-只会平移均值，所以给定输入的 x，y 的值服从高斯分布，均值为 $\mathbf{w}^\top \mathbf{x} + b$
所以 y 服从
$$P(y \mid \mathbf{x}) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{1}{2\sigma^2} (y - \mathbf{w}^\top \mathbf{x} - b)^2\right)$$
根据极大似然估计：即所有情况同时发生的情况下，使得这个概率最大，所有情况同时发生用联合概率得到 $$P(\mathbf{y} \mid \mathbf{X}) = \prod_{i=1}^{n} p(y^{(i)} \mid \mathbf{x}^{(i)})$$
通过取对数可以将乘法化为加法，由于历史原因求最小更容易，所以可以再同时取负得到 $$-\log P(\mathbf{y} \mid \mathbf{X}) = \sum_{i=1}^{n} \frac{1}{2}\log(2\pi\sigma^2) + \frac{1}{2\sigma^2} \left(y^{(i)} - \mathbf{w}^\top \mathbf{x}^{(i)} - b\right)^2$$
第一项可以忽略，因为 $\sigma$ 假设为常数，然后第二项除去 $\frac{1}{\sigma^2}$ 之后就和上面平方误差一样了
## Softmax 回归
主要用于分类任务中，比如我们在任务中希望 $\hat{y}$ 输出是每种类别的概率，然后再根据 $argmax(\hat{y})$ 将概率最大的一项变为 1，然后其他变为 0
但是为规范化的 $\hat{y}$ 并不是我们所感兴趣的输出，因为它可能是很大的数，也可能是负数，这是由于在对特征进行计算的时候得到的
所以我们引入了 $$softmax(o)=\frac{e^x}{\sum_{n=1}^ke^n}$$ 这个公式可以将输出限定在 `0-1` 的范围内，并且所有输出之和为 `1`, $softmax$ 并不会改变输出之间的大小顺序，只是将它们都限定在了一个范围
### Cross-Entropy Loss
当二分类时，交叉熵损失函数公式如下 $$l = - [y \log(\hat{y}) + (1-y) \log(1-\hat{y})]$$
当预测错误时，惩罚力度都很大，损失会趋于∞
扩展到多分类时，公式变成 $$l(\mathbf{y}, \hat{\mathbf{y}}) = -\sum_{j=1}^{q} y_j \log \hat{y}_j$$
因为此时的 $y$ 是一个 one-hot 编码，只有真实类别对应的那项不为 0，其余都为零
在计算梯度时，由于我们要先对 $l$ 求导，要得到 $\frac{\partial l}{\partial o} = \frac{\partial l}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial o}$
所以根据链式求导法则，我们先分开在合并
$$\frac{\partial l}{\partial \hat{y}} = -\frac{y(1-\hat{y}) - \hat{y}(1-y)}{\hat{y}(1-\hat{y})} = -\frac{y - y\hat{y} - \hat{y} + y\hat{y}}{\hat{y}(1-\hat{y})} = \frac{\hat{y} - y}{\hat{y}(1-\hat{y})}$$
然后对于
$$\frac{\partial \hat{y}_i}{\partial o_i} = \frac{e^{o_i} \cdot S - e^{o_i} \cdot e^{o_i}}{S^2} = \frac{e^{o_i}}{S} \cdot \frac{S - e^{o_i}}{S}$$
由于 $\frac{e^{o_i}}{S} = \hat{y}_i$$$\frac{\partial \hat{y}_i}{\partial o_i} = \hat{y}_i (1 - \hat{y}_i)$$
合并之后 $$\frac{\partial l}{\partial o}=\hat{y} - y$$
#### 信息量
我们假如不能完全准确预测某个事件，我们可能会感到惊异，于是信息量用来量化这种惊异程度
$$
\log{\frac{1}{P(j)}} = -\log{P(j)}
$$
当这件事发生概率越小，但它发生了的话，我们就可能会感到更加惊异
#### 交叉熵
我们把熵 $H(P)$ 看作是主观概率为 $Q$ 的观察者所看到概率为 $P$ 的惊异程度。这里的 $Q$ 即为 $\hat{y}$，$P$ 则为 $y$，当 $y$ 和 $\hat{y}$ 相反的时候，熵就会特别大

### 重新审视 Softmax
在 softmax 函数中 $$softmax(o)=\frac{e^x}{\sum_{n=1}^ke^n}$$
这时会出现一个问题，当某个 $e^n$ 特别大的时候，可能超出了数据类型能表达的最大数值时，会 overflow，会使分母无穷大，最后得到的预测值可能为 0, inf, nan，所以我们无法在此时得到一个准确的值
其中一个方法是，在计算所有值的时候，先将每个 x 减去这个最大值 n，再进行计算，由于每个 x 都向左平移 n 个单位，所以最后计算的值不变，但是可能会出现较大负值，在取 e 后接近于 0，最后在计算交叉熵的时候会出现 $log(0)=-inf$，在经过反向传播后会变成 `nan`

为了避免数值稳定问题，我们直接对公式进行化简，将 softmax 和交叉熵结合在一起
$$\log(\hat{y}_j) = \log \left( \frac{\exp(o_j - \max(o_k))}{\sum_k \exp(o_k - \max(o_k))} \right)$$

$$= \log(\exp(o_j - \max(o_k))) - \log \left( \sum_k \exp(o_k - \max(o_k)) \right)$$
$$= o_j - \max(o_k) - \log \left( \sum_k \exp(o_k - \max(o_k)) \right)$$
然后再来看后面 $log()$ 函数里，由于 $o_k-max(o_k)$ 里至少有一项是 $o_k==max(o_k)$，所以至少括号里面肯定大于等于 0
