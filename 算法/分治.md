## 快排
- 确定分界点
- 调整范围
- 递归处理左右两段
```
void quick_sort(int q[], int l, int r){
	if(l >= r) return;
	
	int x = q[(l + r) / 2], i = l-1, j = r+1;
	while(i < j){
		do i++;while(q[i] < x);
		do j--;while(q[j] > x);
		if(i < j) swap(q[i], q[j]); 
	}
	
	quick_sort(q, l, j);
	quick_sort(q, j+1, r);
}
```
## 归并
- 找分界点 mid = (l+r)/2
- 递归排序 left 、right
- 归并---将两个有序数列合二为一
